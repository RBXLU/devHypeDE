# Значки HypeDE

Собственные значки приложений среды. Тема запасная (`hicolor`), поэтому они
находятся в любой системе, какая бы тема значков ни была выбрана.

## Как устроено

* `scalable/apps/*.svg` — исходники;
* `32x32`, `48x48`, `64x64`, `128x128`, `256x256` — растровые копии.

Растровые копии не прихоть: если в системе не настроен загрузчик SVG для
gdk-pixbuf, приложение покажет вместо значка заглушку. С копиями значок
останется на месте.

## Правило: в SVG значков не должно быть комментариев

Отрисовщик значков в GTK разбирает SVG собственными средствами и на
многострочном комментарии молча отдаёт пустое изображение — вместо значка
появляется заглушка «картинка не найдена». Ошибка не попадает ни в журнал, ни
в вывод `rsvg-convert`, которому такой файл нравится, поэтому ищется она долго.

Поэтому пояснения к значкам живут здесь, а сами файлы содержат только формы.

## Что нарисовано

| Файл | Значок |
|---|---|
| `dev.hypede.Files` | синяя папка на белом круге |
| `dev.hypede.Settings` | серая шестерёнка на белом круге |
| `dev.hypede.Launcher` | сетка из девяти синих точек |

Круг — общая форма: на полке значки стоят в ряд, и одинаковая внешняя форма
собирает ряд в единое целое.

## Как обновить растровые копии

```bash
cd assets/icons/hicolor
for size in 32 48 64 128 256; do
  for f in scalable/apps/*.svg; do
    rsvg-convert -w $size -h $size "$f" -o "${size}x${size}/apps/$(basename "${f%.svg}").png"
  done
done
```
