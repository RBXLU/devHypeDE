# Дорожная карта

Порядок выбран по одному правилу: сначала то, без чего средой нельзя
пользоваться каждый день, потом то, что делает её приятной.

## 0.1 — основание (сделано)

- [x] Композитор на smithay: окна, фокус, ввод, рабочие столы
- [x] Плиточная раскладка с зазорами и полноэкранным режимом
- [x] Движок анимаций с пружинами и перенацеливанием
- [x] Палитра из одного акцента с проверкой читаемости
- [x] Файл настроек, горячие клавиши, протокол управления, `hypectl`
- [x] Панель, файловый менеджер, параметры, поиск приложений
- [x] Пакет для Arch и CachyOS

## 0.2 — облик и железо (сделано)

- [x] Бэкенд DRM/KMS: несколько мониторов, переключение консолей
- [x] Минималистичный облик: тёмная полка, круглые значки, панель быстрых
      настроек, поиск приложений сеткой
- [x] Обои с режимами «заполнить», «вписать», «по центру»
- [x] Свои значки, обои и звуки
- [x] Меню и всплывающие панели (xdg-popup) с вписыванием в экран
- [x] Тема курсоров и звуки — через настройки

## 0.2 — настоящий сеанс

Здесь среда перестаёт быть «вложенной игрушкой» и становится тем, во что можно
войти с экрана входа.

- [x] **Бэкенд DRM/KMS** — работа на настоящем железе без внешнего сеанса
- [x] **Несколько мониторов** — выстраиваются слева направо, подключение на ходу
- [ ] **Свои рабочие столы на каждом мониторе** — сейчас они общие
- [ ] **wlr-layer-shell** — панель становится настоящим слоем, а не окном,
      узнаваемым по `app_id`; заодно заработают waybar, wofi и прочие
- [ ] **Курсоры и темы курсоров**
- [ ] **xdg-decoration** — договорённость с клиентом о том, кто рисует рамку
- [ ] **Блокировка экрана** (`ext-session-lock`)
- [ ] **Отрисовка по повреждённым областям** вместо постоянного кадра

## 0.3 — окна ведут себя как положено

- [ ] **Перетаскивание и изменение размера мышью**
- [ ] **Плавное изменение размера окна** своими элементами отрисовки
- [ ] **Прозрачность и затемнение неактивных окон**
- [ ] **Обзор окон** (`Super+Tab`) с уменьшенными копиями содержимого
- [ ] **Скругление углов и тени** на стороне композитора
- [ ] **Размытие под полупрозрачными слоями**
- [ ] **XWayland** — без него не запустятся старые программы и часть игр

## Чего в планах нет

Чтобы не расползалось:

- совместимость с расширениями GNOME или виджетами KDE;
- собственный тулкит — GTK 4 достаточно;
- поддержка X11 как основного режима (только XWayland для старых программ).
