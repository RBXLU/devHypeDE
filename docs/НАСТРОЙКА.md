# Что в HypeDE можно настроить

Коротко: **почти всё, и одним файлом**. Ниже — полный перечень с примерами.

Все настройки живут в `~/.config/hypede/config.toml`. Файла может не быть —
среда запустится со значениями по умолчанию. Менять можно как файл, так и
приложение «Параметры»; оба пишут одно и то же.

Применить изменения без перезапуска сеанса:

```bash
hypectl dispatch reload      # или Super+Shift+R
```

## Оформление

```toml
[theme]
name = "Мой стиль"
accent = "#1a73e8"        # из него строится вся палитра
variant = "light"         # light или dark — схема окон
shell_variant = "dark"    # схема полки и поиска приложений
spacing = 6.0             # шаг сетки отступов

[theme.radii]
small = 8.0
medium = 14.0
large = 22.0
window = 16.0             # скругление окон

[theme.typography]
family = "Inter"
monospace_family = "JetBrains Mono"
size_pt = 10.5

[theme.effects]
panel_opacity = 0.92
popover_opacity = 0.98
blur_radius = 32.0
inactive_dim = 0.04       # насколько тускнеет окно без фокуса
```

Достаточно поменять `accent` — остальная палитра пересчитается, и читаемость
проверится автоматически. Схема оболочки задаётся отдельно от схемы окон:
полка лежит поверх обоев, и тёмная подложка одинаково уверенно читается на
любых.

## Анимации

```toml
[theme.motion]
scale = 1.0               # 0 полностью выключает движение
base_ms = 220

[animations.window_open]
enabled = true

[animations.window_open.curve.spring]
stiffness = 500.0
damping_ratio = 0.55      # < 1 даёт перелёт, 1 — движение без колебаний
mass = 1.0
epsilon = 0.001

[animations.window_close]
enabled = true

[animations.window_close.curve.timed]
duration = { secs = 0, nanos = 140000000 }
easing = "ease-in-quad"
```

Настраиваются по отдельности: появление и закрытие окна, перестроение
раскладки, переключение рабочего стола, всплывающие панели, обзор окон. Для
каждой можно выбрать либо пружину, либо длительность с кривой сглаживания —
доступны все кривые из `easings.net`, включая произвольную `cubic-bezier`.

## Окна и раскладка

```toml
[layout]
mode = "tiling"           # tiling или floating
gaps_inner = 8.0
gaps_outer = 12.0
border_width = 2.0
workspaces = 9
master_ratio = 0.55       # доля экрана под главным окном
```

## Полка

```toml
[panel]
enabled = true
position = "bottom"       # bottom или top
height = 48
pinned = ["dev.hypede.Files", "dev.hypede.Settings", "foot", "firefox"]
show_workspaces = true
show_clock = true
show_battery = true
```

В `pinned` пишется либо идентификатор `.desktop`-файла, либо просто команда.

## Обои

```toml
[wallpaper]
path = "/home/имя/Изображения/моё.png"
mode = "fill"             # fill, fit, center или color
```

Без `path` берутся встроенные обои среды из `/usr/share/hypede/wallpapers`.

## Курсор

```toml
[cursor]
theme = "Adwaita"
size = 24
```

Подойдёт любая тема курсоров из `/usr/share/icons`. Своей темы курсоров у
HypeDE нет: готовые наборы сделаны аккуратнее, чем вышло бы наспех. Если
названной темы в системе не нашлось, показывается встроенная стрелка —
остаться вовсе без указателя хуже, чем показать не тот.

## Звуки

```toml
[sound]
enabled = true
volume = 0.5
theme_dir = "/home/имя/звуки"   # свой набор вместо встроенного
```

Файлы в наборе: `startup.wav`, `notification.wav`, `volume.wav`, `error.wav`,
`logout.wav`.

## Ввод

```toml
[input]
keyboard_layout = "us,ru"
keyboard_options = "grp:alt_shift_toggle"
repeat_delay_ms = 400
repeat_rate = 30
pointer_accel = 0.0       # от -1 до 1
natural_scroll = false
tap_to_click = true
focus_follows_mouse = false
```

## Горячие клавиши

Свои привязки **полностью заменяют** набор по умолчанию — иначе от ненужной
привязки невозможно было бы избавиться.

```toml
[[keybind]]
keys = "Super+B"
do = "spawn"
command = "firefox"

[[keybind]]
keys = "Super+Shift+Q"
do = "close-window"

[[keybind]]
keys = "Super+3"
do = "workspace"
index = 3
```

Полный список действий: `hypectl help`.

## Что нельзя переопределить

Две вещи работают всегда, независимо от настроек:

* `Ctrl+Alt+F1`…`F12` — переключение виртуальной консоли;
* `Ctrl+Alt+Backspace` — аварийный выход из сеанса.

Свой набор привязок заменяет стандартный целиком, и без этих двух лазеек из
сеанса на видеокарте было бы не выйти вовсе.

## Автозапуск

```toml
autostart = [
  "nm-applet",
  "telegram-desktop",
]
```

## Значки

Свои значки приложений кладутся в `~/.local/share/icons/hicolor/scalable/apps`.
Если в системе нет загрузчика SVG для gdk-pixbuf, положите рядом растровые
копии — подробности в `assets/icons/README.md`.

## Чего пока нельзя

Честный список:

* редактировать горячие клавиши мышью — только через файл;
* менять состав плиток в панели состояния;
* задавать правила для отдельных приложений («это окно всегда плавающее»);
* настраивать несколько мониторов по отдельности.

Всё это в [дорожной карте](ДОРОЖНАЯ-КАРТА.md).
